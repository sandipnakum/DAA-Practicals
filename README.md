# 📘 Design and Analysis of Algorithms (DAA) Lab

Welcome to my **Design and Analysis of Algorithms (DAA)** practical repository. This repository contains the implementation of various algorithms along with their time complexity analysis as part of the DAA laboratory.

## ⏱️ Time Complexity

| Algorithm | Best | Average | Worst |
|-----------|------|---------|-------|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) |
| Linear Search | O(1) | O(n) | O(n) |
| Binary Search | O(1) | O(log n) | O(log n) |
| Iterative Factorial | O(n) | O(n) | O(n) |
| Recursive Factorial | O(n) | O(n) | O(n) |
| 0/1 Knapsack | O(nW) | O(nW) | O(nW) |

## 🎯 Objectives

- Understand the design and analysis of algorithms.
- Compare algorithm performance.
- Study time complexity and space complexity.
- Learn divide-and-conquer, greedy, recursion, and dynamic programming techniques.

## 📖 Learning Outcomes

After completing these experiments, students will be able to:

- Implement standard algorithms.
- Analyze algorithm efficiency.
- Compare different approaches to solving problems.
- Apply Dynamic Programming and Divide & Conquer techniques.
- Write optimized C++ programs.
